Export from Windows: Event Viewer → right-click the log → Save All Events As… → keep the .evtx format, then copy it to whichever machine you are reading it on.

What you get: every field Windows stores in the record — provider, event ID, level, timestamps, process and thread IDs, user SID, and all event data — plus the raw XML.

An event log identifies people and machines. Account names, SIDs, the computer name, client addresses, and full command lines are all recorded verbatim, and command lines and script blocks sometimes carry passwords. Mask hides the values of those named fields everywhere they appear — the list, the detail pane, the XML, and both exports. Domain SIDs and the account segment of user-profile paths go wherever they appear. It is a strong best effort rather than a guarantee: some providers park account names in positional fields like param7, which no name list can anticipate, so read a record before sharing it.

What is missing: the rendered description text. Windows builds that at display time from the provider's message DLL, which lives on the machine that wrote the log, so it is not inside the file. Event data fields carry the same information.
