Capture one in Chrome or Edge: DevTools → Network → tick Preserve log, reproduce the issue, then right-click the request list → Save all as HAR with content. Without with content the response bodies are left out.

Firefox: Network → gear icon → Save All As HAR. Safari: enable the Develop menu, then Network → Export.

What you get: every request and response the browser recorded — full header sets, query and form parameters, cookies, request payloads, response bodies, status and timing breakdowns, remote IP, protocol, initiator call stack, and the raw entry JSON.

A HAR usually holds live credentials. Auth headers, session cookies, and bearer tokens are captured verbatim. Mask hides the values of named fields — headers, cookies, query parameters, and form parameters — and HAR exports a filtered copy with the same masking applied. Response bodies are never masked, so read those yourself before sharing a capture.
